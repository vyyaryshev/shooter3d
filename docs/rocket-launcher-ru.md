# Пусковая установка без взлёта

`RocketLauncher` запускает те же префабы с `MechRocket` сразу в сторону игрока.
Каждая ракета получает случайное отклонение при запуске и затем летит прямо.
Вертикального взлёта и преследования нет. Огненный хвост и взрыв сохраняются.

1. Сохрани сцену/префаб и добавь `RocketLauncher` на объект пусковой установки.
2. Назначь свой префаб ракеты с `MechRocket` в `Rocket Prefab`.
3. В `Launch Point` назначь пустой объект у выхода ствола, снаружи препятствий.
   Без ссылки используется позиция самой установки.
4. Назначь `Target` или оставь пустым для поиска игрока с тегом Player.
5. Если установка — дочерняя часть врага, назначь корень врага в `Owner`,
   чтобы ракеты игнорировали все его коллайдеры.

По умолчанию: автоматический огонь в пределах 30 м, 3–5 ракет в залпе,
интервал 0,3 с, пауза между залпами 8 с. `Launch Spread Angle` — угловой разброс
(3 градуса), `Launch Position Spread` — разброс начальной позиции в метрах (0,1).
Нулевые значения отключают соответствующий разброс.
Разброс `MechRocket.Spread Angle` относится к прежнему режиму с подъёмом;
при прямом запуске применяется только разброс установки.

Отключи `Automatic Fire`, если нужен запуск через UnityEvent кнопки/триггера:
вызови `RocketLauncher.FireSalvo()`. В Play Mode та же команда есть в контекстном
меню компонента. Незавершённый залп прерывается при отключении установки,
смерти через HealthChanged, оглушении или выходе цели из радиуса.
На корне врага с Health компонент получает эти сообщения напрямую.

Если установка стоит на том же роботе, который уже запускает ракеты через
`ISOMechAI`, отключи там прежний ракетный запуск, иначе будут работать обе системы.
Текущий запуск ISO Mech с подъёмом сохранён; новый прямой режим выбирает RocketLauncher.

Проверка после сохранения сцены: установка выпускает залп без подъёма вверх,
точки старта и курсы слегка различаются, модели смотрят по курсу. Если отойти
после выстрела, уже выпущенные ракеты не доворачиваются за игроком. Стена
перехватывает ракеты и вызывает взрыв. Автоматического запуска Play Mode нет.
