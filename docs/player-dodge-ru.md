# Уворот игрока

В `FirstPersonMovement` добавлен уворот на левый или правый Ctrl.
Компонент уже есть на игроке из `First Person Controller Minimal`, поэтому
добавлять новые компоненты и пересохранять префаб не требуется.

- WASD/стрелки + Ctrl: уворот в выбранном направлении относительно корпуса.
- Ctrl без направления: уворот назад.
- Направление фиксируется при нажатии, удержание Ctrl не повторяет уворот.
- По умолчанию нужен контакт с землёй: 3 м за 0,2 с, перезарядка 1 с от начала.
- Уворот не даёт неуязвимости. Вертикальная скорость и гравитация сохраняются.
- При открытом меню со свободным курсором ввод уворота не принимается.

В Inspector у FirstPersonMovement раздел **Dodge**: Dodge Key, Dodge Distance,
Dodge Duration, Dodge Cooldown, Dodge Only On Ground. В расширенном контроллере,
если используется `Crouch`, переназначь его Ctrl на другую клавишу во избежание
одновременного приседания. На текущем Minimal-контроллере этого компонента нет.

Ввод считывается в Update, чтобы не пропускать короткие нажатия. Движение Rigidbody
выполняется в FixedUpdate. Перед каждым шагом SweepTest проверяет форму коллайдера
по направлению уворота и ограничивает движение до ближайшего препятствия.

## Проверка в Editor

Сначала сохрани сцену; автоматического запуска Play Mode нет.
Проверь Ctrl с WASD и без ввода, диагональ, удержание Ctrl, повторное нажатие во
время перезарядки, попытку уворота в воздухе и уворот вплотную к стене.
Персонаж не должен проходить сквозь стену, ускорять диагональный уворот или
зависать в воздухе. После уворота обычное движение должно возобновляться.
