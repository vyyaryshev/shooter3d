# Враг ISO Mech

Это отдельный робот-паук ISO Mech, не SpiderOrange. Он ходит по NavMesh,
стреляет по игроку по очереди из четырёх пушек и каждые 6–10 секунд
пытается подойти для удара пушками. Если подойти за 6 секунд не получилось,
возвращается к стрельбе. Во время сближения и удара не стреляет.

## Создание

1. Дождись завершения компиляции Unity. Выйди из Play Mode.
2. Выбери **Tools → Shooter3D → Create ISO Mech Enemy**.
3. В `Assets/Prefabs/ISOMechEnemy` появится готовый `ISOMechEnemy.prefab`,
   снаряд, URP-материал и Animator Controller с Idle, Walk и Death.
   Повторный запуск создаёт другую папку, сохраняя предыдущий вариант.
4. Открой новый префаб. Проверь четыре `FirePoint_Shotgun...` внутри костей
   пушек: передвинь их к концам стволов. Начальные позиции приблизительные.
   Синий Z корня робота должен смотреть вперёд модели.
5. Перетащи префаб на запечённый NavMesh. У игрока должен быть тег `Player`,
   Collider/CharacterController и `Health`. Цель также можно назначить в поле `Player`.
6. Для арены/засады добавь этот новый префаб в список спавна.

Сцена и исходный HDRP-префаб не меняются командой сборки. Если ты редактировал
сцену, сохрани её перед самостоятельным добавлением нового робота.
Исходные FBX и текстуры должны оставаться на месте: они используются новым префабом.

## Как устроено

На корне находятся `NavMeshAgent`, `CapsuleCollider`, кинематический `Rigidbody`,
`Health`, `EnemyController` и `ISOMechAI`. Дочерний `Visual` содержит модель и Animator.
Движением управляет агент, поэтому **Apply Root Motion выключен**: анимация
перебирает ногами, но не перемещает корень второй раз.

В комплекте нет клипа удара. Скрипт добавляет поворот костей `ShotgunTop_L/R`
и `ShotgunBot_L/R` поверх обычной анимации, а при выстреле — небольшую отдачу.
Удар наносит урон один раз после замаха, если игрок остался близко,
перед роботом и между ними нет препятствия. Это удар в ближнем бою.

Здоровье общее с остальными врагами. При смерти AI прекращает действия,
проигрывается Death, `EnemyController` удаляет объект через 3 секунды.
Сообщение `PlayerMeleeHit` прерывает атаку и временно оглушает робота.
Не добавляй на этого врага `MutantAI`, `SoldierRangedAI` или `SpiderWallClimber`:
одновременное управление будет мешать движению.

## Основные настройки ISOMechAI

| Поле | Значение |
| --- | --- |
| Detection Range | Дальность обнаружения, 30 м |
| Shooting Distance | Дистанция остановки для стрельбы, 10 м |
| Shot Interval / Shot Damage | Интервал между выстрелами / урон одного снаряда |
| Bullet Speed | Скорость снаряда |
| Cannon Aim Speed | Скорость наведения пушек, в градусах в секунду |
| Max Cannon Aim Angle | Максимальное отклонение пушек от направления корпуса |
| Melee Interval | Случайная пауза между попытками ближней атаки |
| Melee Range / Melee Damage | Дальность / урон удара |
| Windup / Recovery | Время замаха / восстановления |
| Cannon Swing Angle | Размах пушек; знак можно поменять, если замах направлен не туда |
| Sight Mask | Слои препятствий и игрока; стены должны входить в маску |

Размер робота при сборке приводится примерно к 2,5 м по высоте.
Подстрой радиус агента и капсулу под нужный масштаб. При появлении над землёй
можно добавить существующий `NavMeshActivationOnLanding`: включить
`Start Falling On Enable` и добавить `ISOMechAI` в `Behaviours To Enable After Landing`.
Без этого компонента префаб нужно ставить непосредственно на NavMesh.

Новый материал использует URP/Lit и общие текстуры для всех LOD.
HDRP Mask Map напрямую не подключается: упаковка каналов отличается;
Metallic и Smoothness заданы константами и доступны в материале.

## Ручная проверка

Сначала сохрани сцену. Запускай Play Mode только когда убедишься, что прежняя
проблема потери сохранений устранена; автоматического запуска нет.

- На NavMesh робот идёт к игроку, ноги анимируются, остановка примерно в 10 м.
- Пушки стреляют по очереди; снаряды уменьшают Health игрока и не ранят владельца.
- Стена перекрывает стрельбу и урон от удара.
- Если игрок за стеной, но есть обход по NavMesh, робот проходит вокруг стены,
  не останавливаясь за 10 метров до конца маршрута. Корпус поворачивается вдоль пути.
- При движении игрока вбок, вверх и вниз пушки плавно следят за ним.
  Синий Z каждой FirePoint должен смотреть из ствола наружу; выстрел ждёт наведения.
- Через 6–10 секунд робот подходит, замахивается и наносит один удар.
  Если отойти во время замаха, урона нет; после удара стрельба возобновляется.
- Игрок на недоступной площадке: попытка сближения прекращается по таймеру.
- Оглушение игроком и смерть прерывают замах без отложенного урона.
- После смерти нет выстрелов, воспроизводится Death и робот удаляется.
